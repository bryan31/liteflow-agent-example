# 本地文件报告

1. 从用户消息或工作区文件中获取数据。信息不足时说明缺失项；仅在用户要求示例数据时自行生成，并标注为示例。
2. 使用已提供的文件工具，以 `report.md` 或 `report.csv` 等相对路径写入工作区。简单内容可直接生成；需要数据处理时，先用文件工具写入脚本和输入文件，再通过 `execute` 调用 `python3` 或 `node`。
3. 再读取文件，核对内容与用户要求一致。
4. 调用 `deliver_artifact`，将相同的相对路径作为 `filePath`，交付可下载附件。
5. 用用户所用的语言简要总结结果。

`execute` 在当前会话工作区运行 Shell、Python 和 Node，解释器由所选本地或 Docker 后端提供。技能加载结果中的 `Files root` 是工作区相对路径；两种后端都使用该路径访问完整的技能文件。生成的业务文件也使用工作区相对路径，文件改动由框架写回所选存储。

可直接运行本技能的 `scripts/generate_report.py`：输入为 JSON 数组文件，每个元素包含 `name` 和 `total`，参数依次为输入 JSON 路径和输出 CSV 路径。

仅根据实际工具返回说明执行结果，依赖缺失时报告错误。命令受 `harness.shell.whitelist` 限制，不要在命令顶层拼接管道或多条命令，多步操作请写成脚本后通过解释器执行。不要启动长期后台进程；子 Agent 工具仍未启用。
